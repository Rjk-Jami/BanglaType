# BanglaType

Modern, zero-dependency Bengali typing and transliteration web app.

## Features
- **Avro Phonetic**: Instant phonetic transliteration (e.g. `amar` → `আমার`, `computer` → `কম্পিউটার`).
- **Jatiyo Keyboard**: Standard National Bengali keyboard layout with on-screen virtual keyboard.
- **English Mode**: Direct Latin text entry.
- **Convert & Paste**: Instant transliteration of English sentences and loanwords to natural Bangla.

## Tech Stack
- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS
- Zero external runtime keyboard dependencies
